# UX guidelines

- Design the empty, loading, error, and recovery states, not only the happy path.
- Every interactive element has an accessible name and visible focus.
- Colour is never the only carrier of meaning.
- Error copy states what happened and what to do next; never blame the user.
- Destructive actions require confirmation and a way back.
- Respect reduced motion and keyboard navigation.
- Copy is short, specific, and consistent with the product glossary.
